Tingda Helper

聽打小幫手

台灣客語離線聽打與字幕打軸工具

An offline tool for Hakka and Mandarin transcription and subtitle timing. Export SRT or TXT.

下載最新版 各平台檔名說明

這是什麼

聽打小幫手是給電台聽打與字幕對時使用的單機工具，操作方式參考 Arctime。你可以在波形上拉字幕、邊聽邊打文稿，再匯出 SRT 或 TXT。程式不必安裝，也不必一直連網；第一次使用「AI 轉初稿」時，才會下載語音辨識模型。

A standalone desktop app: place subtitle blocks on a waveform, type while listening, and export SRT or TXT. No installer and no constant internet connection are required.

主要功能

  • 波形加上字幕塊，邊聽邊對時
  • 文稿區按 Enter 自動打軸
  • 點文稿區的句子，波形與影片會跳到該句時間
  • 快捷鍵、吸附、警示、尋找取代、專案存檔
  • 匯出 SRT 或 TXT（檔案本身不加標註）
  • 本機 AI 轉初稿（whisper.cpp）：預設 Taiwan-Tongues 客語＋國語模型，也可選 Whisper turbo，或自行載入本機模型檔
  • 模型只需第一次下載，之後可完全離線使用
  • 介面支援七種語言：繁體中文、英文、簡體中文、日文、韓文、越南文、印尼文
  • 免安裝桌面版，提供 Windows 與 Mac（Apple 晶片／Intel）

第一次開啟

Windows

這份程式尚未做程式簽章，Windows 可能會出現 SmartScreen「Windows 已保護你的電腦」。請按「更多資訊」，再按「仍要執行」。這是免安裝版本，下載後直接開啟即可。

Mac

這份程式尚未通過 Apple 簽章與公證，第一次開啟可能會看到「無法打開，因為無法確認開發者」，或提示「已損毀，無法打開」。不是檔案壞掉，而是被 macOS 擋下來。請依下列方式打開：

  1. 先把 .tar.xz 解壓縮（可雙擊，或在「終端機」執行 tar -xJf 檔名.tar.xz），會得到「聽打小幫手.app」。建議把它拖到「應用程式」資料夾。
  2. 按住 Control 鍵再點一下「聽打小幫手.app」（或按右鍵），選「打開」，接著在提示視窗再按一次「打開」。
  3. 如果還是被擋下來，請打開「終端機」，執行：
xattr -cr /Applications/聽打小幫手.app

然後再從「應用程式」打開一次。也可以到「系統設定」→「隱私權與安全性」，在被擋下的提示旁按「仍要打開」。每次下載新版後都要再執行一次上述指令。

AI 轉初稿

第一次使用「AI 轉初稿」時，程式會從 Hugging Face 下載模型（預設是 Taiwan-Tongues 客語＋國語模型，約 3.2 GB，下載後會在本機轉成約 1.1 GB）。下載完成並核對檔案後，之後就可以完全離線使用。華語模型（Whisper turbo）也在選單裡，可另外下載。

AI 轉初稿視窗會註明「初稿由 AI 產生，請人工校對」，並附授權說明。匯出的 SRT / TXT 不會加上註記。
